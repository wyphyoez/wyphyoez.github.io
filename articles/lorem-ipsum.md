---
title: A note on keeping interfaces honest
date: 2026-08-03
tags:
  - Interface design
  - Product thinking
---

Good interface design is often less about adding something and more about removing uncertainty.

A button should say what will happen. A heading should tell the visitor where they are. A page should not present a placeholder link as if it were a finished destination. These choices are small, but together they decide whether a site feels trustworthy.

I try to treat every visible detail as a promise. If the promise is not ready, the interface should make that clear. If it is ready, the path to it should be obvious.
